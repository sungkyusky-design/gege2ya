# Strike Zone 3D (Godot 연습 프로젝트)

지금 Python 총게임(`shooter.py`)을 **진짜 3D**로 옮겨 가는 첫 단계예요.
적 병사 6명을 모두 쓰러뜨리면 승리! 총에 맞은 적은 피를 흘리고 쓰러져요.

## 1. Godot 설치 (맥, 처음 한 번만)

1. https://godotengine.org/download/macos/ 에 들어가요.
2. **Godot Engine** 버튼을 눌러 받아요 (지금 최신: 4.7.2).
   - 아래쪽 **.NET** 버전 말고 위쪽의 일반 버전이에요. (.NET은 C#용이라 우리는 필요 없어요)
3. 받은 zip을 더블클릭해서 풀면 **Godot.app** 이 생겨요.
4. Godot.app 을 **응용 프로그램(Applications)** 폴더로 끌어다 놓아요.
5. 더블클릭해서 켜요.
   - "확인되지 않은 개발자" 같은 경고가 뜨면:
     **시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 "그래도 열기"** 를 눌러요.

## 2. 이 프로젝트 받기

1. https://github.com/sungkyusky-design/gege2ya/archive/refs/heads/main.zip 을 받아요.
2. zip을 풀면 `gege2ya-main` 폴더가 생기고, 그 안에 `godot_fps` 폴더가 있어요.

## 3. Godot에서 열기

1. Godot를 켜면 **프로젝트 매니저** 창이 나와요.
2. **가져오기(Import)** 버튼을 누르고 `gege2ya-main/godot_fps/project.godot` 파일을 골라요.
   (또는 `project.godot` 파일을 프로젝트 매니저 창에 끌어다 놓아도 돼요)
3. **가져오기 & 편집** 을 누르면 편집기가 열려요. 처음엔 준비하느라 몇 초 걸려요.
4. 오른쪽 위 **▶ (실행)** 버튼을 누르거나 **Cmd + B** 를 누르면 게임이 시작돼요.
5. 끝낼 때: **ESC** 로 마우스를 풀고 → 창을 닫거나 편집기의 **■ (정지)** 버튼 (**Cmd + .**)

## 조작

키는 키보드 '위치'로 읽어서, 한글 입력 상태여도 잘 돼요.

| 키 | 동작 | 마우스로는 |
| --- | --- | --- |
| W A S D | 이동 | |
| Shift | 달리기 (W와 함께) | |
| Space | 점프 | |
| C | 앉기 / 일어나기 | |
| ← → ↑ ↓ | 시점 돌리기 | 마우스 움직이기 |
| F | 사격 (꾹 누르면 연사) | 왼쪽 클릭 |
| E | 정조준 (빨간 점 조준기) | 오른쪽 클릭 |
| Enter (또는 F11) | **전체 화면** 켜기/끄기 | |
| R | 죽었거나 이겼을 때 다시 시작 | |
| ESC | 마우스 풀기 (다시 클릭하면 잡혀요) | |

## 전체 화면

- 게임 중 **Enter** 를 누르면 전체 화면, 다시 누르면 창 모드로 돌아와요.
- 창 왼쪽 위 **초록색 버튼**을 눌러도 돼요.
- 처음부터 전체 화면으로 켜고 싶으면: 편집기 메뉴 **프로젝트 → 프로젝트 설정 → 표시 → 창 → 모드**를 **Fullscreen** 으로 바꿔요.

## 게임 규칙

- **적**: 처음엔 돌아다니다가, 앞쪽에서 나를 보면 쫓아와서 쏴요. 뒤로는 못 봐서 몰래 다가갈 수 있어요.
  한 번 나를 보거나 총에 맞으면 계속 쫓아와요.
- **맞히기**: 몸통 3발, **머리 1발(헤드샷)**. 맞으면 피가 튀고 붉게 번쩍여요.
  총알이 지나간 뒤쪽 벽·바닥에 핏자국이 남고, 쓰러진 자리엔 피 웅덩이가 퍼져요.
- **히트마커**: 맞히면 하얀 X, 쓰러뜨리면 빨간 X, 헤드샷은 큰 빨간 X.
- **체력**: 왼쪽 아래 숫자. 4초 동안 안 맞으면 다시 차요. 많이 다치면 화면이 붉어져요.
  앉아 있거나 달리면 적 총에 덜 맞아요.

## 소리

소리 파일 없이 코드(`sfx.gd`)로 만들어요.

- **내 발소리**: 가볍고 짧은 "톡". 달리면 빨라지고 앉으면 작아져요. 착지할 때도 나요.
- **적 발소리**: 무거운 군화 "쿵" + 장비 "찰칵". **소리 나는 방향에서 들려요**
  (이어폰을 끼면 왼쪽/오른쪽이 구분돼요). 가까울수록 커요.
- 내 총소리 / 적 총소리(더 낮고 멀리서 울림), 맞히는 소리, 헤드샷 "띵", 맞았을 때 소리

## 파일 설명

| 파일 | 내용 |
| --- | --- |
| `project.godot` | 프로젝트 설정 (창 크기, 처음 열 장면) |
| `main.tscn` | 맵: 땅, 벽, 건물, 엄폐물, 상자, 드럼통, 해, 하늘, 화면 표시 |
| `player.tscn` | 플레이어: 몸, 카메라(눈), 총 모양 |
| `player.gd` | 플레이어 코드: 이동, 점프, 앉기, 시점, 사격, 체력, 발소리 (**Python과 거의 같은 문법이에요**) |
| `enemy.tscn` | 적 병사 모양 (다리, 몸, 머리, 헬멧, 총) |
| `enemy.gd` | 적 코드: 돌아다니기, 발견하면 쫓아와서 쏘기, 맞기, 쓰러지기 |
| `blood.gd` | 피 효과: 튀는 핏방울, 핏자국, 피 웅덩이 |
| `sfx.gd` | 효과음 만들기 |

## 직접 바꿔 보기 (연습)

- **더 빨리 뛰기**: `player.gd` 맨 위 `SPRINT_SPEED := 8.5` 를 `12.0` 으로 바꾸고 실행해 보세요.
- **더 높이 점프**: `JUMP_VELOCITY := 4.8` 을 `8.0` 으로.
- **상자 더 날리기**: `SHOT_FORCE := 12.0` 을 `40.0` 으로.
- **적을 쉽게/어렵게**: `enemy.gd` 의 `DAMAGE := 7` (적 총 피해), `RUN_SPEED := 3.4` (쫓아오는 속도).
- **적 더 넣기**: 편집기 왼쪽 장면 목록에서 `Enemies` 안의 `Enemy1` 을 고르고 **Cmd + D** (복제) 한 뒤, 화살표를 끌어 옮겨요.
- **맵 고치기**: 편집기 왼쪽 **장면** 목록에서 `Walls` 안의 건물을 고르고, 화면에서 화살표를 끌어 옮겨 보세요.
  저장은 **Cmd + S**.
