## ⬇️ 받아서 바로 하기 (가장 쉬움, Python 필요 없음)

### 🪟 Windows

**[Games.exe 받기](https://github.com/sungkyusky-design/gege2ya/releases/latest/download/Games.exe)** → 받은 파일 더블클릭. 끝!

- 처음 켤 때는 몇 초 걸려요.
- 파란 창 **"Windows의 PC 보호"** 가 뜨면 **추가 정보 → 실행** 을 누르세요 (인터넷에서 받은 새 프로그램이라 한 번 확인하는 거예요).

### 🍎 Mac (M1 이후 Apple Silicon 맥)

**[Games-mac.zip 받기](https://github.com/sungkyusky-design/gege2ya/releases/latest/download/Games-mac.zip)** → 받은 ZIP을 더블클릭해서 풀면 **Games** 앱이 나와요. (응용 프로그램 폴더로 옮겨 두면 편해요.)

애플 개발자 인증이 없는 앱이라 **처음 한 번만** 이렇게 열어 주세요.

1. **Games** 앱을 더블클릭 → "열 수 없습니다 / 확인할 수 없습니다" 창이 뜨면 **완료(또는 확인)** 를 눌러 닫아요.
2. **시스템 설정 → 개인정보 보호 및 보안** 으로 가서 아래로 내리면 *"Games"이(가) 차단되었습니다* 옆에 **그래도 열기** 버튼이 있어요. 누르고 암호를 입력해요.
3. 다음부터는 그냥 더블클릭하면 열려요.

> "Games이(가) 손상되었기 때문에 열 수 없습니다" 가 뜨면 터미널에 아래를 붙여넣고 다시 열어 보세요.
> ```bash
> xattr -dr com.apple.quarantine ~/Downloads/Games.app
> ```
> (앱을 다른 곳으로 옮겼다면 경로를 바꿔 주세요.) 인텔 맥이라면 아래 "Python으로 하기" 방법을 쓰세요.

### 업데이트

- 한 번 받으면 다음부터는 **더블클릭만** 하면 돼요. 매번 받을 필요 없어요.
- 게임이 새 버전으로 바뀌어도 받아 둔 앱은 **자동으로 바뀌지 않아요.**
  대신 앱을 켤 때 새 버전이 있으면 메뉴에 **NEW VERSION AVAILABLE** 이 뜨고, **U** 를 누르면 다운로드 페이지가 열려요.
  거기서 다시 받으면 최신 버전이에요 (맥은 새로 받으면 "그래도 열기"를 한 번 더 해야 할 수 있어요).
- 메뉴 오른쪽 아래에 지금 앱의 버전(`version abc1234`)이 보여요.
- `main` 브랜치에 코드가 올라오면 GitHub가 앱을 자동으로 새로 만들어요 (`.github/workflows/build-apps.yml`).

## 💻 내 컴퓨터에서 하기 (Python으로)

컴퓨터에서 실행하면 브라우저보다 훨씬 빠르고 선명해요. Mac이거나, 코드를 직접 고쳐 보고 싶을 때 이 방법을 쓰세요.

### 1. 처음 한 번만: Python 설치

1. https://www.python.org/downloads/ 에서 **Download Python** 버튼을 눌러 설치해요.
2. **Windows**: 설치 첫 화면 아래쪽의 **"Add python.exe to PATH"** 를 꼭 체크하고 설치하세요.

### 2. 게임 받기

GitHub 저장소 페이지에서 초록색 **Code** 버튼 → **Download ZIP** → 압축 풀기.
(git을 쓴다면 `git clone https://github.com/sungkyusky-design/gege2ya.git`)

### 3. 실행

| 컴퓨터 | 방법 |
| --- | --- |
| Windows | 폴더 안의 **`run_windows.bat`** 더블클릭 |
| Mac | 폴더 안의 **`run_mac.command`** 를 오른쪽 클릭 → **열기** (처음 한 번은 보안 확인이 떠요) |
| 직접 실행 | 터미널에서 `pip install -r requirements.txt` 후 `python main.py` |

실행 파일이 필요한 `pygame`을 알아서 설치하고 게임 선택 메뉴를 열어요.
메뉴에서 숫자 **1** 또는 **2**를 누르면 시작하고, 게임 중 **ESC**를 누르면 메뉴로 돌아와요.

## 스트라이크 존 (1인칭 총게임)

밀리터리 분위기의 1인칭 슈팅 게임입니다 (둠·울펜슈타인 방식의 레이캐스팅). 효과음도 있어요 (M으로 끄기).
세 가지 모드가 있어요.

- **캠페인 (100라운드)**: 20라운드 × 5세트, 맵 22개가 차례로. 라운드마다 맵이 바뀌고, 적이 늘어나고, **적의 실력도 올라가요**.
- **좀비 모드**: 핏빛 달이 뜬 마을에서 끝없이 몰려오는 좀비 웨이브를 버텨요. 점수로 탄약을 사고 총을 강화해요.
- **미션 (장기 작전)**: 아주 큰 맵(64×44칸)에서 다섯 단계로 이어지는 긴 작전. 단계마다 체크포인트에 저장돼요.

**RPG**: 싸울수록 계급이 오르고, 계급과 점수로 **새 무기를 얻고**, 무기는 쓸수록 **레벨이 올라 강해지고**, 계급마다 받는 포인트로 **스킬**을 배워요.
시작하기 전에 **로드아웃**(시작 무기 / 두 번째 무기 / 퍼크)을 골라요.
컴퓨터 속도에 맞춰 화면 선명도를 자동으로 조절해요 (P로 확인).

### 시작 화면

게임을 고르면 조작법과 팁이 나와요 (한글 글꼴이 있는 컴퓨터에서는 한글로). 게임 중에도 **H** 로 다시 볼 수 있어요 (보는 동안 일시정지).

| 키 | 동작 |
| --- | --- |
| Enter | 캠페인 (고른 세트의 첫 라운드부터) |
| ← → | 시작 세트 고르기 (도달한 세트까지: 1, 21, 41, 61, 81라운드) |
| Z | 좀비 모드 |
| O | **미션** 고르기 |
| R | **사격장** (연습, 경험치·저장 없음) |
| X | **도전 모드** (오늘의 도전, 헤드샷만, 권총만, 하드코어, 60초) |
| V | **기록** 화면 + **저장 옮기기** (웹 ↔ 맥) |
| A | **업적**과 누적 기록, 위장 무늬 고르기 |
| K | **스킬** |
| D | **난이도** 바꾸기 |
| C | 이어하기 (저장된 라운드부터) |
| T | 해상도 바꾸기: 1280×720 → 1600×900 → 1920×1080 → 2560×1440 (컴퓨터에서. 모니터보다 크면 전체 화면으로) |
| S | **설정** |

### 설정 (시작 화면에서 S)

↑↓ 로 고르고 ←→ 로 바꿔요. 저장돼서 다음에도 그대로예요.

| 설정 | 내용 |
| --- | --- |
| LOOK SPEED | 화살표 키 / 패드 스틱으로 시점 돌리는 속도 (×0.4 ~ ×2.5) |
| MOUSE SPEED | 마우스 감도 |
| AIM ASSIST | 조준 보정 세기: OFF / LOW / NORMAL / HIGH |
| FIELD OF VIEW | 시야각 56 ~ 90 (넓을수록 많이 보이지만 적이 작아 보여요) |
| VOLUME | 소리 크기 |
| MUSIC | 배경 음악 크기 (0이면 꺼짐). 컴퓨터(맥/윈도우)에서만 나와요 |
| DIFFICULTY | 난이도 5단계 (시작 화면에서 **D** 로도 바꿔요) |
| SQUADMATES | 같이 싸우는 AI 동료 수 0 / 1 / 2 (기본 2, 다음 판부터) |
| UI SIZE | 글자와 화면 표시 크기 80% ~ 130% (다음 판부터 적용) |
| SCREEN SHAKE | 쏘거나 맞을 때 화면 흔들림 켜기/끄기 (어지러우면 OFF) |
| SOUND MARKS | 발소리(회색 점)·총소리(주황 삼각형) 방향을 조준점 둘레에 표시. 소리를 못 들을 때 좋아요 |
| COLORBLIND | 색약 모드: 빨강/초록 대신 주황/파랑 (조준선, 체력, 적 표시) |
| CONTROLS | **키 바꾸기** (Enter 로 열기) |

**키 바꾸기 (설정 → CONTROLS)**: ↑↓←→ 로 기능을 고르고 Enter, 그다음 원하는 키를 누르면 바뀌어요.
이미 다른 기능이 쓰던 키를 고르면 두 키가 **서로 바뀌어요**. Backspace 는 모두 처음대로, ESC 는 저장하고 돌아가기.
ESC, Enter, 화살표(시점)는 바꿀 수 없어요. 도움말(H)과 화면 아래 안내는 처음 키 기준으로 적혀 있어요.

| 난이도 | 적 실력 | 내가 받는 피해 |
| --- | --- | --- |
| RECRUIT | 70% | 45% |
| EASY | 85% | 65% |
| NORMAL | 100% | 100% |
| HARD | 120% | 135% |
| VETERAN | 140% | 180% |

**화살표 키 가속**: 화살표를 톡 치면 아주 조금(정밀 조준), 꾹 누르고 있으면 점점 빨라져요.

맥 **시스템 설정 → 블루투스**에서 컨트롤러를 연결하고 게임을 켜면 바로 돼요 (게임 중에 연결해도 돼요).

### 로드아웃과 무기 인벤토리

모드를 고르면 로드아웃 화면이 나와요. **↑↓** 로 줄을 고르고 **←→** 로 바꾸고 **Enter** 로 시작해요 (**K** 스킬, **ESC** 뒤로).

- **시작 무기 / 두 번째 무기(Q로 바꾸는 무기)**: 가진 무기 중에서 골라요.
- **전술 장비 (N 으로 던지기, 라운드마다 2개)**: **섬광탄**(7칸 안의 적이 최대 3.5초 멍해져요. 나도 바라보면 눈부셔요),
  **연막탄**(10초 동안 연기가 적의 시야를 막아요), **투척 칼**(조용히 꽂혀요. 눈치 못 챈 적은 한 번에, 빗나가면 돌아와요).
- **총기 개조 (로드아웃에서 G)**: 지금 고른 무기의 조준경·총구·탄창·손잡이를 골라요. 무기 레벨이 오르면 새 부착물이 풀려요.
  | 칸 | 부착물 (필요 무기 레벨) |
  | --- | --- |
  | 조준경 | 가늠쇠, 도트(1), 홀로(3, 살짝 확대), 4배율(6, 크게 확대·느려짐) |
  | 총구 | 없음, 보정기(3, 반동 감소), 소음기(8) |
  | 탄창 | 기본, 확장 탄창(2, 1.5배), 빠른 탄창(4, 재장전 25% 빠름) |
  | 손잡이 | 없음, 앵글 그립(3, 그냥 쏠 때 정확·조금 빠름), 수직 그립(5, 반동 크게 감소) |

  바꾸면 성능 막대가 초록(좋아짐)/빨강(나빠짐)으로 보여요. 개조를 안 한 무기는 예전처럼 처치 수로 풀린 부착물이 자동으로 붙어요.
- **수류탄 쿠킹**: **G 를 꾹 누르고 있으면** 핀을 뽑은 채로 쥐고 있다가, **떼면** 던져요. 쥐고 있던 만큼 빨리 터져요
  (화면에 남은 시간). 너무 오래 쥐면 손에서 터져요!
- **인벤토리**: 아래쪽에 무기 14종이 모두 보여요. 가진 무기는 레벨, 없는 무기는 얻는 조건이 나와요.
- 게임에서는 **가진 무기를 전부** 들고 다녀요: **1~9, 0** 으로 바로, **Tab** 으로 다음 무기, **Q** 로 방금 쓰던 무기.

| 퍼크 | 효과 |
| --- | --- |
| HEAVY ROUNDS | 총알 피해 +25% |
| QUICK HANDS | 재장전·무기 교체 40% 빠르게 |
| LIGHTFOOT | 이동 12% 빠르게 + **적이 내 발소리를 못 들어요** |
| IRON SKIN | 최대 체력 130 |
| SCAVENGER | 탄약 1.5배, 수류탄 +2 |

### RPG: 계급, 무기 얻기, 무기 레벨, 스킬

**계급(RANK)**: 처치·헤드샷·목표·라운드 클리어로 경험치를 모으면 1000마다 계급이 올라요. 계급마다 **스킬 포인트 1점**.

**무기 얻기**: 처음엔 소총과 권총만 있어요. 조건을 채우면 **그 순간 바로** 인벤토리에 들어와서 숫자 키로 꺼내 쓸 수 있어요.

| 무기 | 얻는 조건 | | 무기 | 얻는 조건 |
| --- | --- | --- | --- | --- |
| 기관단총 | 계급 2 | | 리볼버 | 한 라운드 1500점 |
| 산탄총 | 계급 3 | | 자동 산탄총 | 계급 8 |
| 점사 소총 | 한 라운드 1000점 | | 기관총 | 계급 10 |
| 기관권총 | 계급 4 | | 유탄발사기 | 한 라운드 2500점 |
| 저격총 | 계급 5 | | 로켓 | 계급 12 |
| 지정사수 소총 | 한 라운드 헤드샷 5번 | | 중돌격소총 | 계급 6 |

**무기 레벨 (1~10)**: 그 총으로 6명 쓰러뜨릴 때마다 레벨 업. **레벨마다 피해 +5%, 재장전 3% 빠르게, 반동 3% 줄어요**.
레벨이 오르거나 부착물이 풀리면 **들고 있는 총에 바로** 적용돼요.

**스킬 (시작 화면이나 로드아웃에서 K)**: ↑↓ 고르기, → 배우기, ← 되돌리기 (언제든 다시 고를 수 있어요)

| 스킬 | 종류 | 효과 (단계마다) |
| --- | --- | --- |
| VITALITY | 패시브 3단계 | 최대 체력 +15 |
| MARKSMAN | 패시브 3단계 | 헤드샷 피해 +15% |
| RELOAD MASTER | 패시브 3단계 | 재장전 10% 빠르게 |
| RUNNER | 패시브 3단계 | 이동 6% 빠르게 |
| REGEN | 패시브 3단계 | 체력이 더 일찍, 30% 더 빨리 차요 |

### 기록과 저장 옮기기 (시작 화면에서 V)

| **고철장** (새 맵) | 흐린 낮 | 폐차 더미, 컨테이너, 크레인, 창고. 차마다 엄폐물 |
| **시장 골목** (새 맵) | 사막의 한낮 | 좁은 노점 골목, 분수 광장, 흙벽돌 집 |
| **석유 시추선** (새 맵) | 폭풍우 치는 밤 | 바다 한가운데 철판 갑판, 탱크, 크레인, 비 |
| BLOOD MOON | 핏빛 달밤 | 좀비 모드 전용 |

라운드가 시작되면 **작전 이름과 임무**가 나와요 (예: OPERATION SANDSTORM). 적은 맵에 맞는 **위장복**을 입어요 (사막: 모래색, 설원: 흰색).

자동차, 불탄 차, 상자, 컨테이너, 모래주머니, 돌담, 쓰레기통, 분수 뒤에 숨으면 총알을 막을 수 있어요 (적도 마찬가지).
맵은 `shooter.py`의 `MAPS`에서 글자를 바꿔 직접 고칠 수 있어요.

- **정조준(E)**: 살짝 확대되고 총알이 덜 퍼져요. 대신 느리게 움직여요.
- **앉기(C)**: 총알이 덜 퍼지고 적이 나를 덜 맞혀요. 대신 느리게 움직여요.
- **달리기(Shift)**: 빠르지만 총이 내려가서 못 쏴요. 멈추면 잠깐 뒤에 쏠 수 있어요.

- 머리를 맞히면 큰 피해(HEADSHOT)! 적의 머리는 내 눈높이보다 살짝 위에 있어요.
- 쏘면 반동으로 시점이 위로 튀어요. 살짝 내리면서 쏘면 잘 맞아요.
- 점프하면 적 총알이 덜 맞지만, 내 총알도 퍼져요.

### 타격감

- **피 효과**: 맞힌 자리에서 피가 튀어요 (헤드샷은 크게). 맞은 적은 붉게 물들고 움찔하며 뒤로 밀려요.
- **쓰러지는 적**: 맞은 방향으로 밀려나며 넘어지고, 바닥에 피 웅덩이와 함께 한동안 남아요.
- **히트마커**: 맞히면 하얀 X, 쓰러뜨리면 빨간 X, 헤드샷은 더 큰 X. 퍽 하는 맞힘 소리.
- **쏘는 느낌**: 위아래·좌우 반동, 총구 섬광, 튀어나오는 탄피 (산탄총은 빨간 탄피).
- **총 화면**: 위장복 소매와 장갑 낀 두 손이 총을 잡고 있어요. 무기마다 생김새(탄창·조준기·개머리판)가 달라요.
  걸으면 흔들리고, 달리면 총을 내리고, 고개를 돌리면 총이 살짝 늦게 따라와요. 쏘면 별 모양 불꽃과 함께 뒤로 밀려요.
- **정조준(E)**: 총을 눈앞으로 들어 도트사이트(빨간 점)나 가늠쇠로 조준해요.
- **손맛 멈춤**: 적을 쓰러뜨리는 순간 화면이 아주 잠깐(0.04초, 헤드샷 0.07초) 멈춰서 묵직하게 느껴져요.
- **마지막 한 명**: 라운드(웨이브)의 마지막 적을 쓰러뜨리면 잠깐 슬로모션.
- **화면 흔들림**: 총이 셀수록 쏠 때 화면이 크게 흔들리고(산탄총·저격총), 맞으면 움찔해요.
- **조준 보정**: 키보드로도 잘 맞도록, 조준점이 적 위에 오면 **조준선이 빨개지고** 시점이 살짝 느려져요.
  아깝게 빗나간 총알은 몸통에 맞게 도와줘요 (조준경 저격은 보정 없음).
- **넉백**: 센 총에 맞을수록 적이 크게 밀려나요.
- **총알 궤적**: 쏠 때마다 총구에서 맞은 곳까지 빛나는 궤적이 날아가요. 적이 쏘는 총알도 궤적이 보여요.
- **탄착 효과**: 빗나간 총알은 벽이나 바닥에 맞아 먼지와 불똥이 튀어요.
- **헤드샷**: 헬멧(모자)이 날아가요. **폭발**로 쓰러뜨리면 살점이 튀어요.
- **장갑 소리**: 중장갑병·보스·브루트·기관총 진지를 맞히면 "깡" 금속 소리가 같이 나요.
- **스치는 총알**: 적 총알이 빗나가면 귀 옆을 "휙" 스치는 소리가 방향에서 들려요.
- **맞은 곳별 반응**: 몸통을 맞으면 옆으로 움찔, 머리를 맞으면 고개가 크게 젖혀져요.
- **쓰러지는 모습 4가지**: 헤드샷은 그 자리에서 털썩, 센 한 방(산탄총·저격총)은 뒤로 날아가고, 폭발은 공중으로 떴다 떨어져요.
- **총소리 메아리**: 쏘면 "탕" 뒤에 울림이 남고, 맵마다 메아리가 달라요 (골목·실내는 크게). 탄피가 바닥에 "짤랑".
- **정해진 반동 모양**: 총마다 반동이 무작위가 아니라 정해진 모양이라, 연습하면 반대로 살짝 돌려 잡을 수 있어요.
- **재장전 동작**: 총을 내리고 탄창을 빼서 떨어뜨린 뒤 새 탄창을 끼워요 ("철컥" 소리). 다 쏘고 하면 노리쇠까지 당겨서 더 오래 걸려요.
- **화면에 피**: 가까이서 쓰러뜨리거나 좀비에게 할퀴이면 화면 가장자리에 피가 묻어요.
- **총구 빛**: 어두운 맵(밤거리, 시추선, 좀비 맵)에서 쏘면 주변이 크게 번쩍여요.
- **정조준 전환**: 정조준을 켜고 끌 때 총이 살짝 내려갔다 올라오며 자연스럽게 바뀌어요.
- **산탄총 한 발씩 장전**: 한 발 넣을 때마다 "착". 장전 중에 쏘면 바로 멈추고 쏴요 (넣은 만큼만).
- **저격총 노리쇠**: 쏠 때마다 총을 살짝 비틀며 노리쇠를 당기는 소리가 나요.
- **총구 연기**: 쏘면 총구에서 연기가 피어올라요. 오래 연사하면 더 많이.
- **무기 살펴보기 (I)**: 총을 옆으로 돌려 보여줘요 (위장 무늬 구경).
- **부서지는 엄폐물**: 나무 상자와 모래주머니는 총알·폭발에 맞으면 부서져서 사라져요 (그 뒤 적이 드러나요!).
  적이 던진 수류탄도 상자를 부숴요. 다시 하기(R)를 하면 원래대로 돌아와요.
- **유리창**: 건물 창문을 쏘면 "쨍그랑" 깨져서 시커먼 구멍이 돼요.
- **벽 자국**: 빗나간 총알은 벽에 총알 자국을, 수류탄·로켓은 그을음을 남겨요.
- **관통 (WALLBANG)**: 상자·모래주머니·돌담 같은 얇은 엄폐물 너머 적도 맞힐 수 있어요 (피해 절반).
- **제압**: 적 총알이 가까이 스치면 화면 가장자리가 어두워지고 조준이 흔들려요. 반대로 내 총알이 적 옆을 스치면 적이 움츠러들어 잘 못 맞혀요.

### 잠입과 손전등

- **알아채기**: 적은 **앞쪽(약 140도)** 만 봐요. 나를 보면 머리 위에 노란 **?** 가 생기고 점점 진해지다가,
  다 차면 빨간 **!** 와 함께 공격해요. 가까울수록 빨리 알아채요. 싸우는 중이거나 아주 가까우면 뒤도 봐요.
- 눈에 띄는 정도: **앉으면 덜**, 달리면 더. **밤 맵은 덜** 띄지만 **손전등을 켜면 훨씬 잘** 띄어요. 총을 쏘면 소리로 알아요.
- **몰래 처치**: 나를 못 알아챈 적 **뒤에서 칼(V)** 로 한 번에 조용히 처치 (`SILENT TAKEDOWN`, 보너스 경험치). 보스는 안 돼요.
- **시체 발견**: 눈치 못 챈 적이 쓰러진 동료를 보면 "MAN DOWN!" 외치고 근처 적들과 그쪽을 수색해요.
- **손전등 (L)**: 밤 맵은 화면 가장자리가 어두워요. 손전등을 켜면 앞이 밝아지지만 적에게 잘 들켜요. 켜면 왼쪽 위에 `LIGHT ON`.

### AI 동료 (ALPHA, BRAVO)

캠페인·좀비·미션에서 **AI 동료**가 같이 싸워요 (설정 **SQUADMATES** 로 0~2명, 사격장·도전 모드에는 없어요).
파란 조끼와 파란 이름표, 미니맵의 **파란 점**이 동료예요. 화면 왼쪽 위에 동료 상태가 나와요.

- 보이는 가장 가까운 적을 쏴요. 쓰러뜨리면 "TANGO DOWN!" (경험치는 절반, 업적 기록에는 안 세요)
- **K 로 명령** (키 바꾸기에서 바꿀 수 있어요): `FOLLOW` 나를 따라와 → `HOLD` 지금 자리에서 대기 → `ATTACK` 적에게 돌격
- 적도 가까이 있는 동료를 쏴요. 동료가 쓰러지면 다음 라운드(미션은 체크포인트)에서 다시 일어나요.
- 내 총알은 동료에게 맞지 않아요. 문은 동료가 가까이 가도 열려요.

### 문과 실내

사무실 건물처럼 **실내가 있는 맵**에서는 위에 **천장**이 보이고, 방 사이에 **문**이 있어요.
문은 나나 적이 가까이 가면 "끼익" 저절로 열리고, 4초 동안 아무도 없으면 닫혀요 (키를 누를 필요 없어요).
닫힌 문은 시야와 총알을 막아요. 문 너머에서 소리가 먹먹하게 들리면 적이 방 안에 있다는 뜻이에요.

### 나침반

화면 위 가운데에 **나침반**이 있어요 (맵 위쪽이 N). 라운드 목표가 있으면 그 방향에 색깔 다이아몬드가 보여요.

### 그래픽: 벽 질감과 조명

- **벽 질감**: 가까운 벽은 벽돌·회반죽·철판·나무판자·돌·콘크리트·모래주머니 무늬가 보여요 (그림 파일 없이 코드로 그려요).
  9칸보다 먼 벽이나, 컴퓨터가 느려서 화면을 거칠게 그릴 때는 예전처럼 단색으로 그려서 빠르게 돌아가요.
- **걷는 적 / 뒷모습**: 적이 걸을 때 다리를 번갈아 들고, 등을 보이면 뒤통수와 배낭이 보여요 (뒤를 잡을 기회!).
- **벽 그림자**: 벽이 땅과 닿는 아래쪽이 어두워서 건물이 땅에 붙어 보여요.
- **가로등 불빛**: 밤 맵에서 가로등 주변이 은은하게 빛나고 바닥에 둥근 불빛이 떨어져요.
- **총구 불빛**: 쏘면 가까운 벽이 순간 주황빛으로 밝아져요 (어두운 맵일수록 크게).
- **번개**: 폭풍우 세트(61~80라운드)의 비 오는 맵에서 가끔 하늘이 번쩍이고, 조금 뒤 천둥이 울려요.

### 소리 (내 발소리 / 적 발소리 구분)

- **내 발소리**: 가볍고 짧아요. 바닥마다 달라요 (모래·잔디는 부드럽게, 도로는 딱딱하게, 나무 부두는 통통, 눈은 사각사각).
  달리면 빨라지고 앉으면 작아져요.
- **적 군화 소리**: 더 낮고 묵직한 "쿵" + 장비가 부딪히는 "찰칵". **소리 나는 방향(왼쪽/오른쪽)에서 들려요** — 이어폰을 끼면 어디서 오는지 알 수 있어요.
  뒤에서 나는 소리는 조금 작게 들려요.
- **좀비 소리**: 질질 끄는 발소리와 그르렁거리는 소리도 방향에서 들려요.
- **적도 내 소리를 들어요**: 걸으면 4.5칸, 달리면 9칸, 총을 쏘면 16칸 안의 적이 소리 난 쪽으로 와요.
  **앉아서 움직이면 조용해요** (LIGHTFOOT 퍼크는 달려도 조용).
- **벽 너머 소리**: 벽에 가려진 적의 총소리·발소리·폭발은 **먹먹하게** 들려요. 또렷하면 보이는 곳, 먹먹하면 벽 뒤예요.
- **총소리 겹치기**: 내 총은 "탕" + 노리쇠 "착" + 가슴을 치는 낮은 "쿵" (센 총일수록 묵직해요).
- **배경 소리**: 맵마다 바람 소리, 비 오는 맵은 빗소리, 밤 맵은 풀벌레 소리가 계속 깔려요. M 으로 같이 꺼져요.
- **배경 음악**: 낮게 둥둥 울리는 긴장감 있는 음악 (컴퓨터에서만, 설정의 MUSIC 으로 크기 조절).
- **체력 회복**: 4초 동안 안 맞으면 체력이 빠르게 차요. 다치면 화면 가장자리가 붉어지고, 체력이 낮으면 심장 소리가 나요.

### 킬스트릭 (X로 사용)

죽지 않고 연속으로 쓰러뜨리면 보상을 받아요. 죽으면 처음부터 다시 세요 (킬스트릭으로 쓰러뜨린 건 안 세요).

| 연속 처치 | 보상 |
| --- | --- |
| 3 | **레이더**: 20초 동안 미니맵에 모든 적이 빨간 점으로 보여요 |
| 5 | **공습**: 조준점이 가리키는 곳(멀면 12칸 앞)에 폭탄 5발이 줄지어 떨어져요. 나는 안 다쳐요 |
| 7 | **자동 포탑**: 2칸 앞에 놓으면 30초 동안 가까이 보이는 적을 알아서 쏴요 |

### 점수와 계급

| 행동 | 경험치 |
| --- | --- |
| 처치 | +100 (헤드샷·칼 +50, 보스 +500) |
| 3초 안에 연속 처치 | DOUBLE KILL +50 / TRIPLE KILL +100 / MULTI KILL +150 |
| 라운드 클리어 | +250 |

경험치 1000마다 **계급(RANK)** 이 올라가요 (왼쪽 위). 저장되니까 껐다 켜도 이어져요.

### 화면 표시

- 맞으면 조준점 둘레에 **어느 방향에서 맞았는지** 빨간 화살표가 떠요 (위 = 앞, 아래 = 뒤).
- 적이 총을 쏘면 미니맵에 잠깐 **빨간 점**으로 보여요.

### 상자

쓰러진 적이 상자를 떨어뜨리고, 맵 곳곳에도 놓여 있어요 (라운드마다 다시 채워져요). 가까이 가면 주워요.

| 상자 | 효과 |
| --- | --- |
| 탄약 (초록 상자) | 모든 무기의 여분 총알 보충 |
| 체력 (흰 상자 + 빨간 십자) | 체력 +35 |
| 수류탄 | 수류탄 +1 (최대 6개) |

### 적

| 적 | 특징 |
| --- | --- |
| 일반병 (GRUNT) | 평범한 적. 체력 100 |
| 돌격병 (RUSHER) | 빨간 모자. 빠르게 달려들어요. 체력 60이지만 가까이서 아파요 |
| 저격수 (SNIPER) | 2라운드부터. 멀리서 쏴요. 쏘기 전에 빨간 불빛이 반짝여요 |
| 중장갑병 (HEAVY) | 3라운드부터. 체력 300. 느리지만 총알을 쉴 새 없이 쏴요 |
| 폭탄병 (BOMBER) | 4라운드부터. 베레모와 허리의 수류탄. 거리를 두고 수류탄을 던져요. 화면에 **GRENADE!** 가 뜨면 피하세요 |
| 방패병 (SHIELD) | 6라운드부터. 앞에서 쏜 몸통 총알은 방패에 막혀요. 머리를 노리거나 옆·뒤로 돌아가거나 폭발/칼로 |
| 보스 (BOSS) | 10라운드마다. 흰 정장. 체력 900, 연사와 수류탄. 쓰러뜨리면 상자 4개. 화면 위에 **보스 체력 막대**.<br>**체력 60% 아래**: 화가 나서 빨라지고 6초마다 나에게 돌진. **30% 아래**: 부하 3명을 부르고 빨간 연막 |
| 측면 공격병 (FLANKER) | 7라운드부터. 검은 복면에 빨간 고글. 크게 좌우로 피하며 빠르게 파고들어 가까이서 산탄총 |
| 의무병 (MEDIC) | 8라운드부터. 흰 옷에 빨간 십자. **근처 적을 치료해요** (머리 위에 초록 +). 먼저 노리세요! |
| 기관총 진지 (GUNNER) | 9라운드부터. 모래주머니 뒤에서 움직이지 않고 쉴 새 없이 쏴요. 옆으로 돌아가거나 수류탄·유탄으로 |
| 정찰 드론 (DRONE) | 12라운드부터. 머리 위에 떠서 빠르게 날아다니며 약한 총을 자주 쏴요. 작아서 맞히기 어렵지만 체력 45 |
| 레이저 저격수 (LASER) | 14라운드부터. 쏘기 전에 **빨간 레이저가 나를 향해 좁혀 와요**. 레이저가 조준점에 닿기 전에 숨으세요! |

**적 실력은 라운드마다 8%씩 올라가요** (라운드 시작 때 `ENEMY SKILL 108%`처럼 보여줘요, 최대 200%).
더 정확하게 맞히고, 더 빨리 반응하고, 더 자주 쏘고, 조금 더 단단해져요. 실력이 오를수록 **옆으로 왔다 갔다 피하면서** 싸워요.

**적의 전술**

- **엄폐**: 일반병·저격수·의무병·폭탄병·방패병은 다치거나, 재장전하거나, 제압당하면 가까운 엄폐물 뒤로 숨어요.
  잠시 뒤 옆으로 **고개를 내밀어** 쏘고 다시 숨기를 반복해요. 가까이 다가가면 엄폐를 포기하고 싸워요.
- **분대 AI**: 적끼리 무전으로 협력해요. 머리 위 **말풍선**으로 무엇을 하는지 알려줘요.
  - `CONTACT!` 한 명이 나를 발견하면, 가까운 동료들이 내가 **마지막으로 보인 곳**으로 찾아와요.
  - `SUPPRESSING!` 멀리 있는 한 명이 자주(덜 정확하게) 쏴서 나를 묶어 둬요.
  - `FLANKING!` 다른 한 명이 내 **옆으로 돌아** 들어와요. 옆과 뒤를 조심!
  - `RELOADING!` 탄창이 비었어요 (지금이 기회). `GRENADE OUT!` 수류탄이 날아와요.
- **길찾기**: 적과 동료가 건물·자동차·바다를 **돌아서** 찾아와요 (문도 열고 들어와요). 예전처럼 벽에 막혀 멈추지 않아요.
- **순찰과 수색**: 나를 못 본 적은 이리저리 순찰하다 잠깐 멈춰 서요. 소리 난 곳에 도착하면 두리번거려요.
- **재장전**: 적도 탄창이 있어요. 다 쏘면 재장전하는 동안 머리 위에 **RELOADING** 이 떠요 — 지금이 치고 들어갈 기회!
- **수류탄**: 한자리에 7초 넘게 숨어 있으면, 나를 보는 적이 수류탄을 던져 끌어내요.

## 쉿, 쳐다보지 마! (SCP-096 추격 게임)

얌전히 있는 SCP-096의 얼굴을 손전등으로 비추면… 미친 듯이 쫓아옵니다.

| 키 | 동작 |
| --- | --- |
| 방향키 / WASD | 이동 (손전등은 움직인 방향을 비춰요) |
| Shift | 대시 (2초 쿨타임) |
| R | 게임 오버 후 다시 시작 |
| ESC | 메뉴로 |

1. 096은 평소엔 손으로 얼굴을 가리고 어슬렁거려요.
2. 손전등으로 096을 비추거나 몸으로 부딪히면 비명을 지른 뒤 쫓아와요.
3. 화면 위 `SURVIVE` 시간이 끝날 때까지 도망치면 점수 +1.
4. 점수가 오를수록 096은 더 빠르고, 더 오래 쫓아와요.
5. 096은 급회전을 잘 못해요. 붙잡히기 직전에 옆으로 꺾으면 피할 수 있어요!

난이도는 `game.py` 맨 위의 설정값(속도, 시간 등)을 바꿔서 조절할 수 있어요.
