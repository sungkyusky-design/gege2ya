# 게임 모음

Python + pygame으로 만든 게임들입니다.

| 게임 | 내용 |
| --- | --- |
| 쉿, 쳐다보지 마! | SCP-096을 놀리고 도망치는 추격 게임 |
| 스트라이크 존: 네온 비치 | 80년대 네온 해변 도시에서 싸우는 1인칭 총게임 |

## 💻 내 컴퓨터에서 하기 (추천)

컴퓨터에서 실행하면 브라우저보다 훨씬 빠르고 선명해요.

### 1. 처음 한 번만: Python 설치

1. https://www.python.org/downloads/ 에서 **Download Python** 버튼을 눌러 설치해요.
2. **Windows**: 설치 첫 화면 아래쪽의 **"Add python.exe to PATH"** 를 꼭 체크하고 설치하세요.

### 2. 게임 받기

GitHub 저장소 페이지에서 초록색 **Code** 버튼 → **Download ZIP** → 압축 풀기.
(git을 쓴다면 `git clone https://github.com/sungkyusky-design/gege2ya.git`)

### 3. 실행

| 컴퓨터 | 방법 |
| --- | --- |
| Windows | 폴더 안의 **`run_windows.bat`** 더블클릭 |
| Mac | 폴더 안의 **`run_mac.command`** 를 오른쪽 클릭 → **열기** (처음 한 번은 보안 확인이 떠요) |
| 직접 실행 | 터미널에서 `pip install -r requirements.txt` 후 `python main.py` |

실행 파일이 필요한 `pygame`을 알아서 설치하고 게임 선택 메뉴를 열어요.
메뉴에서 숫자 **1** 또는 **2**를 누르면 시작하고, 게임 중 **ESC**를 누르면 메뉴로 돌아와요.

## 🌐 브라우저에서 바로 하기

**https://sungkyusky-design.github.io/gege2ya/**

설치 없이 링크만 열면 돼요. 첫 화면에서 **Enter**(또는 클릭), 메뉴에서 숫자를 누르면 시작해요.
브라우저에서는 Python이 느리게 돌아서 컴퓨터에서 실행할 때보다 화면이 거칠어요.
`main` 브랜치에 코드가 올라오면 웹 버전이 자동으로 다시 만들어져요 (`.github/workflows/deploy-web.yml`).

## 스트라이크 존: 네온 비치 (1인칭 총게임)

노을 지는 80년대 해변 도시를 무대로 한 1인칭 슈팅 게임입니다 (둠·울펜슈타인 방식의 레이캐스팅).
적을 모두 쓰러뜨리면 다음 라운드로 넘어가고, 라운드마다 적이 늘어나요.
컴퓨터 속도에 맞춰 화면 선명도를 자동으로 조절해요 (F3으로 확인).

### 맵

| 구역 | 특징 |
| --- | --- |
| 해변 | 바다, 모래사장, 보드워크, 야자수 |
| 호텔 안뜰 (위-서쪽) | 분수가 있는 안뜰. 좁은 입구 두 곳으로만 들어가요 |
| 오피스 골목 (위-동쪽) | 높은 유리 타워 사이 좁은 골목 |
| 주차장 (가운데-서쪽) | 빽빽하게 세워진 차들 사이 |
| 공원 (가운데-동쪽) | 동상과 야자수가 있는 잔디밭 |
| 공사장 (아래-서쪽) | 나무 상자로 만든 미로 |
| 시장 골목 (아래-동쪽) | 가게 사이 한 칸짜리 좁은 골목 |

자동차, 상자, 쓰레기통, 분수 뒤에 숨으면 총알을 막을 수 있어요 (적도 마찬가지).
맵은 `shooter.py`의 `GAME_MAP`에서 글자를 바꿔 직접 고칠 수 있어요.

### 조작 (키보드만으로 다 할 수 있어요)

| 키 | 동작 | 마우스로는 |
| --- | --- | --- |
| W A S D | 이동 | |
| 스페이스바 | 점프 | |
| ← → / ↑ ↓ | 시점 돌리기 (좌우 / 위아래) | 마우스 움직이기 |
| F | 사격 (꾹 누르면 연사) | 왼쪽 클릭 |
| E | 정조준 켜기/끄기 (저격총은 조준경) | 오른쪽 누르고 있기 |
| Z | 저격총 배율 바꾸기 (3 → 6 → 12배) | 조준경 보면서 휠 |
| G | 수류탄 던지기 (위를 볼수록 멀리) | |
| V | 칼 공격 | |
| 1 ~ 6 | 무기 바꾸기 | 휠 |
| Q | 방금 쓰던 무기로 | |
| R | 재장전 / 게임 오버 후 다시 시작 | |
| F3 | FPS와 화면 선명도 표시 | |
| F11 | 전체 화면 (컴퓨터에서) | |
| ESC | 메뉴로 | |

### 무기

| 무기 | 특징 |
| --- | --- |
| 1 소총 (RIFLE) | 꾹 누르면 연사. 몸통 3발 |
| 2 권총 (PISTOL) | 한 발씩. 정확하고 재장전이 빨라요 |
| 3 저격총 (SNIPER) | 조준경 3/6/12배. 몸통 150 / 머리 300. 조준경으로 보면 안개가 걷혀요 |
| 4 산탄총 (SHOTGUN) | 8발이 퍼져 나가요. 가까이서 강력 |
| 5 기관단총 (SMG) | 아주 빠른 연사, 대신 한 발 피해는 작아요 |
| 6 로켓 (ROCKET) | 날아가서 터지는 범위 공격. 정통으로 맞으면 중장갑병도 한 방 |
| 수류탄 (G) | 벽과 바닥에 튕기다 1.8초 뒤 폭발. 라운드마다 3개 |
| 칼 (V) | 바로 앞 적에게 큰 피해 |

- **정조준(E)**: 살짝 확대되고 총알이 덜 퍼져요. 대신 느리게 움직여요.
- 폭발은 벽 뒤 적은 못 맞혀요. 너무 가까이서 터지면 나도 다쳐요.
- 머리를 맞히면 큰 피해(HEADSHOT)! 적의 머리는 내 눈높이보다 살짝 위에 있어요.
- 쏘면 반동으로 시점이 위로 튀어요. 살짝 내리면서 쏘면 잘 맞아요.
- 점프하면 적 총알이 덜 맞지만, 내 총알도 퍼져요.

### 상자

쓰러진 적이 상자를 떨어뜨리고, 맵 곳곳에도 놓여 있어요 (라운드마다 다시 채워져요). 가까이 가면 주워요.

| 상자 | 효과 |
| --- | --- |
| 탄약 (초록 상자) | 모든 무기의 여분 총알 보충 |
| 체력 (흰 상자 + 빨간 십자) | 체력 +35 |
| 수류탄 | 수류탄 +1 (최대 6개) |

### 적

| 적 | 특징 |
| --- | --- |
| 일반병 (GRUNT) | 평범한 적. 체력 100 |
| 돌격병 (RUSHER) | 빨간 모자. 빠르게 달려들어요. 체력 60이지만 가까이서 아파요 |
| 저격수 (SNIPER) | 2라운드부터. 멀리서 쏴요. 쏘기 전에 빨간 불빛이 반짝여요 |
| 중장갑병 (HEAVY) | 3라운드부터. 체력 300. 느리지만 총알을 쉴 새 없이 쏴요 |

## 쉿, 쳐다보지 마! (SCP-096 추격 게임)

얌전히 있는 SCP-096의 얼굴을 손전등으로 비추면… 미친 듯이 쫓아옵니다.

| 키 | 동작 |
| --- | --- |
| 방향키 / WASD | 이동 (손전등은 움직인 방향을 비춰요) |
| Shift | 대시 (2초 쿨타임) |
| R | 게임 오버 후 다시 시작 |
| ESC | 메뉴로 |

1. 096은 평소엔 손으로 얼굴을 가리고 어슬렁거려요.
2. 손전등으로 096을 비추거나 몸으로 부딪히면 비명을 지른 뒤 쫓아와요.
3. 화면 위 `SURVIVE` 시간이 끝날 때까지 도망치면 점수 +1.
4. 점수가 오를수록 096은 더 빠르고, 더 오래 쫓아와요.
5. 096은 급회전을 잘 못해요. 붙잡히기 직전에 옆으로 꺾으면 피할 수 있어요!

난이도는 `game.py` 맨 위의 설정값(속도, 시간 등)을 바꿔서 조절할 수 있어요.
