# 게임 모음

Python + pygame으로 만든 게임들입니다.

## 🎮 브라우저에서 바로 하기

**https://sungkyusky-design.github.io/gege2ya/**

설치 없이 링크만 열면 돼요. 처음 열 때 로딩이 조금 걸리고, 화면을 한 번 클릭하면 시작해요.
`main` 브랜치에 코드가 올라오면 웹 버전이 자동으로 다시 만들어져요 (`.github/workflows/deploy-web.yml`).

## 💻 내 컴퓨터에서 하기

```bash
pip install -r requirements.txt
python main.py
```

`main.py`를 실행하면 게임 선택 메뉴가 나와요. 게임 하나만 바로 하고 싶으면:

| 게임 | 실행 |
| --- | --- |
| 쉿, 쳐다보지 마! (SCP-096 추격) | `python game.py` |
| 스트라이크 존 (1인칭 총게임) | `python shooter.py` |

게임 중에 ESC를 누르면 메뉴로 돌아가요.

## 스트라이크 존 (1인칭 총게임)

옛날 둠·울펜슈타인 방식(레이캐스팅)으로 만든 1인칭 슈팅 게임입니다.
맵에 숨어 있는 적을 모두 쓰러뜨리면 다음 라운드로 넘어가고, 라운드마다 적이 늘어나요.

| 키 | 동작 |
| --- | --- |
| W A S D | 이동 |
| 마우스 (또는 ←/→) | 시점 돌리기 |
| 마우스 왼쪽 | 사격 (꾹 누르면 연사) |
| R | 재장전 / 게임 오버 후 다시 시작 |
| ESC | 종료 |

- 머리를 맞히면 한 방에 쓰러져요 (HEADSHOT).
- 연사할수록 총구가 위로 튀고, 움직이면서 쏘면 총알이 퍼져요.
- 적은 처음 발견하고 잠깐 뒤에 쏘기 시작해요. 먼저 보고 먼저 쏘세요!

## 쉿, 쳐다보지 마! (SCP-096 추격 게임)

얌전히 있는 SCP-096의 얼굴을 손전등으로 비추면… 미친 듯이 쫓아옵니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| 방향키 / WASD | 이동 (손전등은 움직인 방향을 비춰요) |
| Shift | 대시 (2초 쿨타임) |
| R | 게임 오버 후 다시 시작 |
| ESC | 종료 |

## 규칙

1. 096은 평소엔 손으로 얼굴을 가리고 어슬렁거려요.
2. 손전등으로 096을 비추거나 몸으로 부딪히면 비명을 지른 뒤 쫓아와요.
3. 화면 위 `SURVIVE` 시간이 끝날 때까지 도망치면 점수 +1.
4. 점수가 오를수록 096은 더 빠르고, 더 오래 쫓아와요.
5. 096은 급회전을 잘 못해요. 붙잡히기 직전에 옆으로 꺾으면 피할 수 있어요!

난이도는 `game.py` 맨 위의 설정값(속도, 시간 등)을 바꿔서 조절할 수 있어요.
